# 工时记 · 自动化长测试

## 运行

```bash
# 环境：node 18+，需要 jsdom
cd build-src/test
npm i jsdom --silent   # 若目录不支持安装，可在 /tmp 建工作副本后把本目录复制过去
bash run-all.sh
```

`run-all.sh` 会依次跑 t1~t9，全部通过时退出码为 0。另有 `e2e.mjs` 用真实 Chrome（puppeteer）跑端到端。

## 覆盖范围

| 文件 | 覆盖内容 |
|---|---|
| t1 | 启动渲染、四工种切换、数据隔离、编辑器打开、快速输入、数字键盘基本输入 |
| t2 | 四工种算法：正式工底薪+加班/事假/缺勤、临时工工时、计件、工地点工/加班/借支、日历与明细金额 |
| t3 | 工作日与「休」标记、节假日 2025-2030、调休补班、手动覆盖、工资周期（含跨年）、现在结算、工资条、防呆校验 |
| t4 | 自定义背景、关于弹窗与源码复制、导出/导入、旧版 v2 迁移、持久化重启、编辑回填与删除、年度累计、非自然月归属、月份边界、计时器 |
| t5 | 设置页键盘输入与联动、自动计薪天数、月度扣款增删、完整记工流程、工种卡片差异、背景持久化、返回键行为 |
| t6 | 非自然月下日历与明细金额一致、四工种同日数据隔离、CSV 导出、年度柱状图、系统打印调用、补贴扣款联动 |

测试全部在 jsdom 中运行：给 `dialog.showModal`、`window.scrollTo`、`canvas` 打了桩，其余均为页面真实 DOM 事件（点击按钮、焦点、键盘按键、输入事件）。

## 说明

- 测试直接操作真实页面元素，大部分用例走 `click` / `focus` / 键盘按钮，少量用 `window.__app` 读取内部状态做断言。
- `window.__app` 是应用内置的只读调试接口，离线单文件里始终存在，不影响正常使用。

| t7 | 导入用户真实备份（20 条记录）并核对金额 |
| t8 | 新旧版本金额对照（导入同一备份结果一致） |
| t9 | 旧 APK SharedPreferences 数据迁移 |
| e2e | 真实 Chrome：键盘输入、记工、切换工种、工资条、背景、刷新持久化 |
