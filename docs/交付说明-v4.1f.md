## 三、这一版的功能（累计）

- **四种工种**：正式工 / 临时工 / 计件 / 工地记工，各有独立的记录、日历、明细和工作日设置，互不影响
- **工资算法**：正式工按底薪 ÷(22×8) 折算时薪，加班 1.5/2/3 倍可调；临时工按工时×单价；计件按品项×数量×单价
- **日历**：内置 1900–2100 年农历自算，2025–2030 节假日（2025/2026 按国务院公布，含调休补班），漏记提醒，非自然月工资周期
- **隐私键盘**：数字 / 英文 / 拼音 26 键 / 九宫格 T9，约 18500 条词库，支持整句（`wojintianjiaban` → 我今天加班）和简拼（`jt` → 今天），长按退格连删，候选翻页
- **自定义壁纸**：相册选图，三个滑块（模糊 0–20px / 压暗 0–75% / 卡片 10–100%），卡片拉到 55% 以下就能透出照片
- **数据**：JSON 备份导出导入、CSV 导出、工资条打印或存图

## 五、请你装上自测（重点看壁纸和拼音，这两个是这次的关键）

点开 `/sdcard/Download/工时记-v4.1f.apk` 安装，然后：

1. **壁纸**（上一版你说"并不能看到壁纸"）
   设置 → 自定义背景 → 选一张自己的照片 → 看能不能直接看到。看不清就拉"卡片"滑块往下调。
   这次改成了独立固定图层，不再用之前那种安卓 WebView 支持很差的写法。

2. **拼音**（上一版你说"体验很差"）

   再试整句 `wojintianjiaban`，试简拼 `jt`，切九键打 `94664` 看是否先出「中」。

3. **农历**：翻到 2027 年 2 月，元宵节应该在 **20 号**（不是 21 号）。

4. **工种切换**：切到临时工，确认日历和明细完全换一套，改它的工作日不影响正式工。

5. **工资周期**：点顶部「自然月」→ 拨到「26号 - 下月25号」→ 看 11 月账是否变成 11/26–12/25。

6. **你的旧数据**：覆盖安装后数据应该还在。如果丢了，用 `/sdcard/Download/工时记备份-2026-11-20.json` 导入。
