# 工时记 v1.0 · 首个对外发布版

> 这是准备发给别人用、并放到 GitHub 上的第一个版本。功能沿用 4.4，主要改的是版本号、包名、关于弹窗、打包方式，另外修掉了一个内置键盘的隐藏问题。

## 一、版本号与包名

| 项 | 旧（4.1f / 4.4） | 新（1.0） |
|---|---|---|
| 网页版本号 `APP_VERSION` | 4.4 | **1.0** |
| `versionName` | 4.1f | **1.0** |
| `versionCode` | 7 | **1** |
| 包名 `applicationId` | `com.dsha.gongshiji` | **`com.deepseekharness.gongshiji`** |

**为什么换包名**：保持原来的包名、只把 versionCode 改成 1 的话，已经装过 4.1f 的手机在安装时会报「应用未安装」（Android 不允许降级安装）。换成新包名后：

- 新老版本可以同时装着，互不覆盖
- 真正做到了「不覆盖更新」
- 代价：旧版的本地数据不会自动迁过来。需要旧版「设置 → 数据与备份」导出 JSON，新版同位置导入

Java 包名和 `namespace` 仍然是 `com.dsha.gongshiji`，只有安装用的 `applicationId` 换了，代码不用动。

## 二、关于弹窗加了 GitHub 地址

在「关于工时记」的联系方式下面，单独加了一块 **GitHub 仓库**：

- 显示 `https://github.com/guomeihuang4-bot/gongshiji`
- 右侧有「复制地址」按钮，点一下复制到剪贴板
- 说明文字：源码、新版 APK、网页版都在这里，可以自己下载、改、重新打包

「键盘不好用？」那块原样保留：**改用手机自带键盘 / 恢复内置键盘** 按钮、当前状态提示、localStorage 记忆都没动。

底部关于源码复制的说明改成符合单文件分发的说法：

> 点「一键复制」复制的是当前页面的完整 HTML（单文件版已含键盘），存成 .html 双击就能用。自己改代码用「主程序 + keypad.js」两个文件，打包 APK 用单文件版。

## 三、打包改成单文件

之前 APK 的 `assets/` 里放的是 `index.html` + `keypad.js` 两个文件。这一版改成**只放单文件版**（`工时记-单文件.html` → `assets/index.html`），键盘已内联，`assets` 里只剩一个文件。

原因：

- 少一次外部资源加载，少一类「键盘没出来」的兼容问题
- 旧版 4.1f 的 APK 本来就是单文件，这是验证过的路径
- 别人拿到的 HTML 也推荐用单文件，一个文件双击就能用

`deploy-assets.sh` 已同步修改，会复制单文件并删掉 `assets/keypad.js`。

4.1f 之后陆续做了这些，1.0 全部包含：

## 五、顺手修掉的一个隐藏问题

写测试时发现：内置键盘打开时会被挂到当前弹窗（`dialog`）里，如果这时保存关闭、下一次打开编辑器，`dialog.innerHTML` 整体重写会把键盘 DOM 一起删掉 —— 之后内置键盘**再也弹不出来**，只能刷新页面。

修了三处：

1. `openEditor` 重写编辑器内容之前，先收起键盘并把它移回 `body`
2. 保存、关闭弹窗时也收起键盘（给所有 `dialog` 加了 `close` 监听）
3. `kpToggle` 打开前检查键盘 DOM，被删了就自动重建（`kpEnsureDom`）

另外把键盘事件绑定从「等 DOMContentLoaded」改成「脚本执行时立即绑定一次，DOMContentLoaded 再幂等补一次」，这样单文件内联时不会被事件时序绕过。
