1. 把键盘样式注入 `<head>`（不再需要单独的 css 文件）
2. 把键盘 DOM 注入 `<body>` 末尾
3. 绑定"点输入框 → 弹键盘"的逻辑
4. 暴露 `window.GongKeypad` 给主程序调用

主程序里原来的 `kpToggle(false)`、`bindKeypadTriggers()`、`kpOpen` 这些直接引用，都改成了走 `GongKeypad` 接口。

### 为什么这么拆

- 主程序从 1.5 MB 降到 219 KB，界面和记账逻辑清爽了
- 键盘可以单独修、单独换，改键盘不碰主程序
- 以后不想要内置键盘了，删掉 `keypad.js` 就行，主程序自动退回用系统输入法

### 分享 / 打包时的注意

- **发给别人**：用 `工时记-单文件.html`，改个名字就行，不用带第二个文件。
- **自己用两个文件也行**，但必须放同一目录。只发 `工时记.html` 的话，页面能开、能记账，点输入框会弹系统输入法，内置键盘没了——不报错，只是静默降级。
- **打包 APK**：`gongshiji-app/app/src/main/assets/` 里放的是 `index.html`，WebView 用 `file:///android_asset/index.html` 加载。把 `工时记-单文件.html` 复制成 `index.html` 覆盖即可，然后 `cd gongshiji-app && ./build.sh assembleDebug`。用单文件版能避开 WebView 加载外部 js 的兼容问题。
- "关于 → 一键复制源码"出来的是主程序 HTML，要带上 `keypad.js` 才有键盘，页面说明已同步改过。

## 修复：点「系统键盘」没反应

**原因**：点「系统键盘」时，代码先把内置键盘收起、把输入框设成可编辑，然后调用 `input.focus()` 想弹系统键盘。但这个 `focus()` 又触发了全局的 `focusin` 监听——它见到输入框就无条件重开内置键盘，顺手把 `readOnly` 设回 true。结果键盘刚收又弹回来，系统输入法永远出不来。

**修法**：加一个 `kpSysTarget` 标记，记下"这次聚焦是用户主动要系统键盘"。`focusin` 碰到这个输入框就放行、清掉标记，不再重开内置键盘；等用户点到别的输入框或失焦后再点回来，标记已清，内置键盘照常恢复。

**实测**：点「系统键盘」后键盘收起、`readOnly` 解除、输入框拿到焦点；再点输入框能切回内置键盘；数字输入框同样有效。

### 这个按钮踩到的坑

编辑器模板里每个输入框都写死了 `readonly` 和 `inputmode="none"`（为了让内置键盘接管）。只把 `readOnly` 设成 false 还不够——`inputmode="none"` 依然会让系统键盘弹不出来。所以切换时会同时清掉这两个属性，并在 `pointerdown`（聚焦之前）兜底清一次，保证动态生成的输入框也能正常用系统键盘。

## 手写功能

内置键盘第五种模式「手写」：半屏手写板，手指写字，识别结果进候选栏，点选上屏。

- 模式栏点「手写」进入
- 手写板高 `clamp(170px, 28vh, 260px)`，停笔约 0.2 秒自动识别
- 候选栏最多 16 个（可翻页），点一下上屏，画板自动清空
- 底部：退格（撤销上一笔，画板空时删输入框的字）、清空、空格、完成
- 数字输入框仍然只给数字键盘，手写按钮自动禁用

### 完全离线

识别全程在本机，不联网、不请求任何资源。

引擎借鉴开源项目 [HanziLookupJS](https://github.com/gugray/HanziLookupJS)：

- 引擎 12 KB 纯 JS，无外部依赖（去掉了原库的 jQuery 依赖）
- 字库衍生自 Make Me a Hanzi 的 `mmah.json`，**9507 个汉字**的笔迹特征，808 KB
- 原库 `init()` 依赖 XHR 拉数据，已改成 `initInline()` 直接从内存解码，静态页面也能跑

## 做了哪些适配

1. **常用字加权**：手写容易把「口/囗」「人/入」「日/曰」搞混，这里用词库自带的《常用字频表》对候选重排，分数接近时常用字优先。实测「口」「人」「日」「十」「大」都能排第一。
2. **切模式清屏**：手写切走再切回，画布与笔画都清空。
3. **尺寸自适应**：横竖屏切换自动重算 canvas 像素，适配高分屏。
4. **键盘高度联动**：手写模式键盘约 367 px（屏幕 44%），弹窗底部留白跟着键盘实际高度走，保存按钮不被挡。

## 已知限制

- **依赖大致正确的笔顺**。「中」标准笔顺是「竖/横折/横/竖」，如果一笔长竖贯穿整个字再画口，会认成近形字。
- 形近字偶尔排第二（「工」常被「土」压到第二），点候选即可。
- 字库以简体楷体为主，生僻字、连笔草书识别率下降。
- 一次识别一个字，连写多个字会被当成一个字匹配。
