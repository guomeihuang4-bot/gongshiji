# 工时记 v4.3（11-26）· 交付说明

> 本次只改「结算」这一处逻辑和文案。没打包 APK，还是直接用网页。

## 一、改了什么

**按钮**：日历页本月工资旁的「算到今天」→ **「结算本月」**（开启后按钮变「恢复整月」，标签显示「已按记录结算」）。

**计算逻辑**：从「按今天之前过了几个工作日折算」，改成 **「只按已经记过工的日子折算」**。

| | 旧（算到今天） | 新（结算本月） |
|---|---|---|
| 依据 | 今天在周期内第几个工作日 | 这个周期里你记过几天 |
| 没记录的日子 | 照给底薪 | **不给** |
| 历史月份 | 不受影响 | 同样按记录算 |

公式：

```
底薪 = 月薪 × 已记录应出勤天数 ÷ 本周期应出勤天数
```

## 二、哪些日子算「已记录」

按天判断，规则只有四条：

| 那天记了什么 | 算不算底薪天数 | 说明 |
|---|---|---|
| 白班 / 早班 / 中班 / 晚班 / 夜班 | ✅ 算 | 正常上一班算一天 |
| 事假 | ✅ 算 | 算一天底薪，再扣一天 → 当天净 0，**不会双扣** |
| 病假 | ✅ 算 | 病假带薪，不扣钱 |
| 休息 | ❌ 不算 | 工作日记「休息」不给底薪 |
| 没记录 | ❌ 不算 | 这就是这次改的核心 |
| 休息日（周末/法定节假日） | ❌ 不算 | 本来就不在计薪天数里 |

举个实例：11 月应出勤 22 天，月薪 8000（日薪 363.64）

- 记了 10 天白班 → 底薪 3,636.36
- 记了 10 天白班 + 1 天事假 → 底薪 4,000（11 天），事假再扣 363.64
- 一天没记 → 底薪 0

## 三、非自然月

直接沿用你的工资周期设置，**不用另外配置**。

设成「26 号起」后，「11 月」这个周期实际是 **11/26 ~ 12/25**：

- 只会数 11/26–12/25 里记过的日子
- 11/20 记的工不会算进这个周期（属于上一个周期）
- 分母也是这个周期自己的应出勤天数

测试里专门验了这条：周期内记 2 天、周期外记 1 天，结果只数 2 天。

## 四、一个要知道的副作用

**开关是全局状态**，打开后**所有月份**都按记录折算，不只是当月。所以：

- 翻到以前的月份，如果当时漏记了几天，那个月的底薪也会跟着变少
- 年度累计跟着变
- 想看回「整月全额」，点「恢复整月」即可，数据不会丢（只是显示口径切换）

如果你希望它只对当月生效、历史月份永远按整月，告诉我，改成那样也就几行。
