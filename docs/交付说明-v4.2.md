## 一、这次做了什么

三件事，对应你点名的两个开源项目。**没有照搬它们的模型**——`daily-work-hours` 是「总工时拆四档、正常档不算钱」，`chunlong-li/jigong` 是包工头管一群工人；你的模型是「底薪 + 加班×倍率」和「四种工种各自记账」，硬套会乱。所以按你的结构重新设计了。

### 1. 加班倍率拆分 + 自动调平

**解决的问题**：公司把节假日和双休对调，同一天的加班被按不同倍率结算；或者明明是 3 倍的法定假日，公司按 2 倍给。

**做法**：一天加班可以拆成「平时 / 周末 / 节假日」三段，改一段，其余两段自动补，**总小时永远不变**。

**在哪用**：日历点某天 → 记工 → 填加班小时 → 点下面的「公司不按法定倍率算？改这里」

- 默认全部落在当天的法定档（跟以前一样，不点开就没变化）
- 想拆：把对应档的小时填进去。比如 4 小时加班，节假日档填 2、周末档填 2，总小时仍是 4
- 改错档会**自动从别的档扣/补**，不会出现「四段加起来对不上总数」
- 底部有实时校验：`合计 4 / 总加班 4 小时 ✓ 对上了`

### 2. 倍率对调损失计算

**解决的问题**：你说的「公司对调，员工收入更少」——现在能直接看到少了多少。

拆开后，明细页会多一行：

> **倍率被调低** −¥41.38
> 按法定倍率应得 ¥124.14，实际 ¥82.76

反过来，如果你按 2 倍记的其实是 1.5 倍的活，会显示「倍率比法定高 +¥…」。
不拆分的时候这一行不出现，所以老数据完全不受影响。

### 3. 调休抵扣

**解决的问题**：公司用调休（补休）换掉加班，这笔钱怎么扣、扣哪一档，得算清楚。

**在哪用**：设置 → 正式工 → **调休抵扣** 卡片

- 填「本月调休小时」
- 选抵扣顺序：
  - **先扣低倍率**（默认）：先抵掉 1.5 倍的加班，3 倍留到最后 → 员工拿得多
  - **先扣高倍率**：先抵掉 3 倍的 → 有些公司就这么扣，选这个才能对上
- 调休超过当月加班总额时，会提示「调休多出 X 小时未抵扣」，不会把工资算成负数

明细页的加班费会变成「加班费（原 4h，抵扣后 2h）」，副标题写明每档剩多少、抵了多少。

### 4. 对外单价 / 到手单价分离

**解决的问题**：谈好一个价、实际到手另一个价（被抽成、被压价），想知道差多少。

**在哪用**：
- 临时工：设置 → 临时工 → 「对外单价（报价）」
- 工地：设置 → 工地 → 「对外单价」三项（日薪 / 时薪 / 加班）

不填 = 和到手价一样，界面上不多任何东西。填了以后，明细页多一行：

> **应收（按对外价）** ¥240
> 差额 ¥40 没到手

## 五、已知限制

- **调休输入后不实时刷新**：填完切一下页面就生效（和其他设置项一样，避免输入时页面重排、丢焦点）
- **日历单日金额不扣调休**：单日格子显示「这天上完能拿多少」，调休是月度行为，只在月度汇总和明细里扣。所以有调休的月份，单日加起来会大于月度汇总，这是有意的
- 倍率拆分只做了正式工。临时工/计件/工地本身的算法里没有「法定倍率」这个概念，硬加会变成另一套系统
- 对外价只做到设置级，没做「某一天单独报价」；如果哪天价格不一样，先用备注记，需要的话我再加
